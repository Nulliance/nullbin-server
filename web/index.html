Start a Null Chat

An end-to-end encrypted group chat. Messages are encrypted in your browser, so only the people you invite can read them, not even the server. When time’s up, it deletes itself.

  • End-to-end encrypted. The server only passes along messages it can’t read.
  • Forward secrecy. Every message has its own key, deleted once it’s used.
  • Safety codes. Compare codes with each other to be sure no one is listening in, the server included.
  • Invite only. Each invite link lets one person in, works for as long as you choose (5 minutes to an hour), and can be revoked.
  • Never on disk. Chats live only in the server’s memory, so a restart also ends them.
  • Tied to this tab. If you close it, you’ll need a new invite to get back in.
